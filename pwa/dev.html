開発モード — 距離減衰と定位

リレーもゲームも無しで、docs/protocol.md §3 の式が実際に鳴る音に載っているかを確かめるページ。 本番と同じ PV.AudioEngine の経路 (source → GainNode → StereoPannerNode → destination) を通す。

停止中

AudioContext は user gesture の後でないと鳴らないので、まず「開始」を押す。

入力 (graph / yaw の代わり)

d と b は 2Hz の graph、yaw は 20Hz の yaw として engine に渡している。 yaw を動かしたときは pan だけが再計算される。

出力

量式の値AudioParam の実測
gain
pan
相対方位 (b − yaw)
可聴 / 購読

実測は GainNode.gain.value / StereoPannerNode.pan.value を毎フレーム読んだ値。 setTargetAtTime で滑らかに追うので式の値へ少し遅れて着く (プチノイズを出さないため)。

gain(d) の曲線

縦 = gain (0〜1)、横 = 距離 0〜80m。破線は 5m (減衰開始) と 60m (可聴限界)。丸が今の位置。

式の自己検査

docs/protocol.md §3 をそのまま当てた期待値との突き合わせ。1 つでも FAIL なら実装が契約から外れている。

このページは開発用のシミュレータであり、実データの位置は一切扱わない。 本番 UI (index.html) には距離も方位も出さない — 出すと配信画面がそのまま ESP になる。
